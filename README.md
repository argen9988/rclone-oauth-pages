# rclone-oauth-pages

Homepage and privacy policy for **rclone-second-brain**, a personal Google OAuth client used only by its owner with [rclone](https://rclone.org/) to sync the owner's own Google Drive. Published with GitHub Pages: <https://argen9988.github.io/rclone-oauth-pages/>

個人使用的 Google OAuth 用戶端（rclone-second-brain）的首頁與隱私權政策，給 Google Cloud 的「品牌」頁填網址用。
